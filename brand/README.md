# CinemaScope logo — usage guide

**The idea:** a C whose opening is the 2.39:1 CinemaScope widescreen frame. The letter is the screen.

Masters are generated by `src/build.py` (`python src/build.py`), so geometry changes go there, not into the SVGs by hand.

## Files (`logo/`)

| File | Use |
|---|---|
| `symbol-sunburst.svg` / `symbol-black.svg` | Symbol on its own, ≥ 32 px |
| `symbol-small-*.svg` | Small-size cut (taller slot) for 16–32 px |
| `tile.svg` / `tile-small.svg` | Sunburst C on a Midnight squircle — app icon, avatar, favicon |
| `horizontal-on-dark.svg` | Primary lockup on Midnight / photography (Sunburst C, white word) |
| `horizontal-on-light.svg` | Primary lockup on white or Sunburst (all Midnight) |
| `horizontal-black.svg` / `horizontal-white.svg` | One-colour print, embroidery, etching |
| `stacked-*.svg` | Square-ish spaces (social, merch) |
| `wordmark-black.svg` | Wordmark on its own |
| `web/` | Favicons, PWA icons, `site.webmanifest`, `<head>` snippet |

`presentation.html` and `slides/` show the mark in context.

## Colour

| | HEX | RGB |
|---|---|---|
| Sunburst | `#F8C61E` | 248 198 30 |
| Midnight | `#252C37` | 37 44 55 |

Use Sunburst on Midnight or Midnight on Sunburst/white. One-colour black and white versions are approved. Sunburst on white has low contrast, so don't use it for small sizes.

## Clear space and sizes

- **Clear space:** the slot height (the 2.39:1 frame) on every side.
- **Minimum size:** symbol 16 px (use the small cut below 32 px); horizontal lockup 96 px wide.
- **Wordmark:** Inter ExtraBold, outlined, tracking −1 %. Inter is SIL OFL, so it's safe to use in a logo.

## Don't

- Rotate or flip the C (the opening always faces right, toward the "screen").
- Change the slot's proportions, round its right end, or close it.
- Add outlines, shadows, gradients or film-strip decoration.
- Set the wordmark in another typeface or recolour the C and the word differently from the files above.
